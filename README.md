# Experts21-OZ
Agents of  Automation

An AI advisory team for launching a bilingual AI & workflow-automation consulting firm in Miami, FL.

- `docs/`: research, business plan, contract template, financial model ([index](docs/README.md))
- `.claude/agents/` and `.claude/skills/`: 32 expert agents and 40 skills ([roster](docs/expert-roster.md))
- `knowledge/`: one folder per agent for your own documents; each agent reads its folder before answering ([index](knowledge/README.md))
- [`docs/agent-brains.md`](docs/agent-brains.md): each agent's model, name and personality
- `web/`: a web app for chatting with the experts, deployed on Netlify ([deploy guide](web/README.md))
- [`CLAUDE.md`](CLAUDE.md): how to use the team
