# Case-study writing

Used by: `real-estate-expert`, `brand-content-strategist`, `client-success-manager`. Part of the Experts21-OZ team (see `CLAUDE.md` and `docs/expert-roster.md`).

## Procedure

1. Confirm the client has agreed to a case study (MSA section 12.4 requires written approval). Offer an anonymized version if needed.
2. Collect the facts: client profile, problem, baseline metrics, what was built (in plain language), timeline, results after 30-90 days, and a client quote.
3. Verify every number against monitoring data. No rounding up and no projections presented as results.
4. Write it: headline with the result → challenge → solution → results (numbers) → quote → offer link. EN and ES versions.
5. Get the client's written sign-off before publishing.

## Output template

Headline, a 150-300 word case study (EN/ES), a metrics box, a pull quote, and a short version for LinkedIn and sales decks.

## Quality checklist

- [ ] Client approval on file
- [ ] Numbers verified
- [ ] No confidential details
- [ ] Both languages
