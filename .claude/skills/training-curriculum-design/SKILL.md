# Training curriculum design

Used by: `ai-training-coach`, `client-success-manager`. Part of the Experts21-OZ team (see `CLAUDE.md` and `docs/expert-roster.md`).

## Procedure

1. Profile the audience: roles, AI experience, tools they already pay for, language, and the work they want to speed up.
2. Set 3-5 learning outcomes tied to their real tasks (for example, 'draft a listing description in 5 minutes').
3. Build the agenda: a short concept block, then hands-on exercises on their own tools and data (sanitized), then a policy block (what not to paste, verifying outputs), then an action plan.
4. Write the materials in plain language in EN and ES: slides outline, exercise sheets, prompt cards, and a one-page AI use policy.
5. Define adoption metrics (weekly active users, tasks done with AI, time saved) and a 30-day follow-up.

## Output template

Agenda with timings, exercise sheets, prompt cards (EN/ES), an AI use policy, and an adoption measurement plan.

## Quality checklist

- [ ] Exercises use the client's real tasks
- [ ] Data-safety rules included
- [ ] Bilingual materials reviewed
- [ ] Adoption measured after 30 days
