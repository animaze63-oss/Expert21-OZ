# Agent Brains and Personalities

Every agent on the Experts21-OZ team has a **brain** (the Claude model set in the `model:` field of its file in `.claude/agents/`) and a **personality** (a first name, a voice and a working style).

## How the brain is chosen

| Brain | Used for | Trade-off | Agents |
|---|---|---|---|
| **opus** | Deep strategy, legal and finance judgment, and coordinating the team | Most capable; slower and costs the most per answer | 7 |
| **sonnet** | Most specialist work: analysis, design, building, writing | Strong all-rounder at moderate speed and cost | 23 |
| **haiku** | Fast, simple lookups: lists, checks, metric pulls | Fastest and cheapest; less depth on hard judgment calls | 2 |

The aliases `opus`, `sonnet` and `haiku` select the current version of each model family. If your plan or organization doesn't allow a model, Claude Code falls back according to its subagent model rules.

## Changing a brain or personality

- **Change the brain:** edit the `model:` line in `.claude/agents/<name>.md`. Valid values are `opus`, `sonnet`, `haiku`, `inherit` (use the same model as the conversation) or a full model ID. Then update the table above.
- **Upgrade for a hard question:** ask the orchestrator to involve an opus agent (for example the chief strategy advisor or CFO). Or ask `agent-architect` to raise an agent's model if its answers are consistently too shallow.
- **Downgrade to save time and cost:** move agents whose work is mostly lookups to `haiku`.
- **Change a personality:** edit the **Your persona** section of the agent file. First names must stay unique, because you can ask for an expert by first name ("ask Victor to rerun the model").
- Or ask `agent-architect` to make the change. It also updates this page and runs `python3 scripts/validate_team.py`.
